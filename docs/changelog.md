# Changelog

RAPTor is currently pre-1.0. Until tagged releases are established, this page
records documentation-visible API changes.

## Unreleased

### Added

- API-focused documentation site.
- Complete reference coverage for the eight current calculation functions.
- Public export of `CompositionSplittingSingleResult`.
- Module-promotion and reproducibility standards.
- Reproducible figures and tables showing representative calculation outputs.
- Hosted-application link at `raptor.engr.wustl.edu`.

Future entries should distinguish API changes from scientific model, database,
or default-setting changes because each has different reproducibility effects.
